OrCAD →to KiCad

Converts an OrCAD Capture .DSN schematic into a KiCad project.

Conversion runs entirely in this browser tab. Your file is not uploaded anywhere.

Drop a .DSN file here

or a .zip archive containing exactly one. You can also paste a copied file.

Options

The preview is drawn by KiCanvas and is indicative only; open the downloaded project in KiCad to check it. Every sheet’s title block shows sheet 1/1 in the preview.
